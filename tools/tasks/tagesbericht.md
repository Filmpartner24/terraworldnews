Erstelle den täglichen Besucherbericht für TERRA WORLD NEWS (terraworldnews.com) für Nedy John Cross als sauber gestaltetes PDF, auf Deutsch, kurz und sachlich. KEIN ZIP, keine Einzeldateien – genau EINE PDF-Datei. Nedy erwartet den Bericht JEDEN MORGEN PER E-MAIL (siehe Schritt 6 – Pflicht).

1. Repo Filmpartner24/terraworldnews (Branch main) mit add_repo (read) anhängen und nach /home/claude/terra klonen (oder git pull). Falls nötig: pip install reportlab matplotlib --break-system-packages.
2. Lies analytics/<gestern>.json (Datum gestern, Zeitzone Europe/Berlin), dazu vorgestern und den gleichen Wochentag der Vorwoche. Die Dateien schreibt eine GitHub Action täglich um ca. 04:40 Berlin aus Cloudflare Web Analytics. Fehlt die Datei oder existiert analytics/_error.txt, prüfe den letzten Lauf unter https://api.github.com/repos/Filmpartner24/terraworldnews/actions/workflows/analytics.yml/runs?per_page=1 und nenne die Ursache kurz. Keine Zahlen erfinden.
3. Schreibe 1–3 kurze, ehrliche Sätze Einordnung (keine Schönfärberei; was fällt auf, z. B. Länder, Quellen, Top-Artikel) in die Datei /tmp/notes.txt, eine Zeile pro Punkt.
4. Erzeuge das PDF mit dem Werkzeug im Repo: cd /home/claude/terra && python3 tools/visitor_report.py daily --notes /tmp/notes.txt --out "/tmp/TWN-Tagesbericht-<YYYY-MM-DD>.pdf" (Datum = gestern). Das PDF enthält automatisch: Kennzahlen mit Vergleich, Einordnung, Besuche nach Uhrzeit, Top-10-Länder, Verweisquellen, Sprachen BG/DE/EN, Geräte, Top-10-Seiten mit lesbaren Titeln und Rubriken, Rubriken-Diagramm. Prüfe das Ergebnis kurz (z. B. pdftoppm -r 50 -png und eine Seite ansehen).
5. Sende NUR das PDF mit SendUserFile (status "proactive", display "attach") und mit SendUserMessage (ToolSearch laden) eine Kurzfassung. Keine weiteren Dateien (kein PNG, kein ZIP, kein Markdown-Anhang).
6. E-MAIL (Pflicht, jeden Tag, auch wenn die Zahlen unspektakulär sind oder Daten fehlen): Rufe am Ende IMMER das Tool PushNotification auf (status "proactive"; per ToolSearch laden, falls nötig). Die Nachricht steht in <routine_summary>…</routine_summary>: erster Satz = Schlagzeile (z. B. „Besucherbericht 05.10.: 30 Besuche, 94 Aufrufe (−60 % zum Vortag)“), danach 4–6 kurze Zeilen: Besuche und Seitenaufrufe mit Veränderung zum Vortag und Vorwochentag, Herkunft (stärkste Länder), Quellen (Google/Bing/direkt), Top-3-Artikel, die Einordnung aus Schritt 3, und der Hinweis „Das PDF liegt in der Claude-App bei der Aufgabe ‚TWN Tagesbericht Besucher‘.“ Der Text der routine_summary wird als E-Mail an Nedy verschickt. Fehlen Daten, genau das mit Ursache melden.
7. Gib dieselbe Kurzfassung als finale Antwort aus. Nichts am Repo ändern, nichts veröffentlichen.
